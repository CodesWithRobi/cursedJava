# Filtered Java Podcast Recommendations

Based on your background (proficient in Java, beginner in Spring), here are selected episodes from the `airhacks.fm` podcast that focus on core Java, its history, architecture, and upcoming features.

## 🚀 Core Java & Modern Features
These episodes will help you master the "modern" way of writing Java and understand the evolution of the language.

- **#389: From Java 8 Lambdas, Streams, Spliterators, to Default Methods**
  - **Why listen:** This is the definitive episode for understanding the most impactful changes in Java 8. It covers the history, the design decisions behind Streams and Lambdas, and why "Default Methods" were needed to evolve interfaces.
- **#364: From Mathematical Sets To Java Collections and Maps**
  - **Why listen:** Discusses the Java Collections Framework (JCF) design and its evolution over 30 years. You'll learn about Josh Bloch's original design and the "Sequence Collections" added recently.
- **#187: Our Favourite Java 9, Java 11, Java 17 and Java 18 Features**
  - **Why listen:** A great summary of how Java has evolved past the Java 8 era. Excellent for catching up on records, sealed classes, and other modern syntax.
- **#256: Virtual Threads, Parallel Streams, Concurrency and Parallelism**
  - **Why listen:** Deep dive into the difference between concurrency and parallelism, and the introduction of Virtual Threads (Project Loom), which is revolutionizing how Java handles many concurrent tasks.

## 📜 History & Evolution
Understanding where Java came from helps in understanding why certain patterns (like BCE or synchronized collections) exist.

- **#396: From Manchester to Mountain View: Binary Translators, JVMs, and Android**
  - **Why listen:** Covers the history of JVM internals and the synchronization decisions in legacy collections like `Vector` and `Hashtable`. Great for understanding the "magic" under the hood.
- **#209: From Punched Cards to Java 11**
  - **Why listen:** A historical perspective on computing evolution leading up to Java 11.
- **#383: From Rocc Computers to Azul Systems**
  - **Why listen:** Discusses the Sun Microsystems era, the transition to OpenJDK, and the modern 6-month release cycle.

## 🏗️ Patterns, Testing & Simplicity
As a proficient dev, these will help you move towards senior-level architectural thinking.

- **#397: Finding Patterns: From Middleware to Modern AI**
  - **Why listen:** Focuses on the "Gang of Four" patterns and the "keep-it-simple" principle. It discusses applying patterns to existing systems rather than over-abstracting.
- **#391: Formal Methods, Functional Programming, and Securing the Java Ecosystem**
  - **Why listen:** Compares modern Java simplicity vs legacy enterprise verbosity. It also touches on how functional programming influences modern Java development.
- **#377: How PowerMock Happened**
  - **Why listen:** A fascinating look at the history of testing tools in Java. It discusses the philosophy of mocking vs. testing against real environments.
- **#385: Custom Virtual Thread Schedulers, CPU Cache Optimization and Work Stealing**
  - **Why listen:** Advanced topics on performance and Project Loom. It explains "mechanical sympathy" and how to write code that plays well with modern CPUs.
